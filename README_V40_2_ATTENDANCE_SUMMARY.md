# v40.2 Attendance Report Summary

The Member Attendance report now shows one row per member with:

- Member ID
- Member name
- Current status
- Days Present (distinct attendance dates marked Present)
- Attendance Days (distinct recorded attendance dates in the selected date range)
- Present % = Days Present / Attendance Days

The selected From/To dates determine the reporting period. The CSV export uses the same one-row-per-member structure.

This change preserves the v40 logo, Advanced Reports consolidation, Headcount, Welfare Due and Finance exports.
