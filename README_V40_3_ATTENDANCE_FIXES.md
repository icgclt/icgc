# v40.3 Attendance improvements

Built from v40.2.

Changes:
- Member Portal shows each member's attendance percentage and present/recorded attendance days.
- Quick Attendance defaults the attendance date to today.
- Quick Attendance can select an upcoming event; selecting an event fills its date and shows the weekday.
- Search now shares toolbar space with date/day instead of occupying the full row.
- Midweek Service is renamed to Bible Study.
- Quick Attendance checkbox state no longer resets when optimistic saves/background sync update attendance data. Searching and marking additional people preserves previously selected boxes.
- Quick Attendance saves against the selected attendance date rather than always using today's date.
